# harness2-ports (archived)

This port now lives as one repository per executor, published under this same
GitHub account:

- **harness2-claude-code** - the Claude Code executor
- **harness2-hermes** - the Hermes Agent executor

Each repository is self-contained: the shared Harness2 core, its executor, its
own test suite, and its own README in the upstream format. This repository is
archived and kept for its history; nothing here is newer than the split.
